## 🚗 [Projeto Android: Carro & Motor com TDD e Coroutines](projetos/MyFirstUnitTest/README.md)

Este projeto foi desenvolvido com o objetivo de praticar **TDD (Test Driven Development)** em um contexto Android, utilizando classes básicas de domínio como `Carro` e `Motor`. A arquitetura inclui **testes unitários**, **testes de aceitação (E2E)** e a utilização de **coroutines com Kotlin Flow**.

---

## 📝 Anotações Incluídas

Além dos projetos, este repositório também contém um material de apoio com resumos dos seguintes tópicos:

- Ciclo de vida do TDD (Red/Green/Refactor)
- Tipos de testes automatizados (Unit, Integration, E2E)
- Pirâmide de Testes do Google
- Diferenças entre TDD Classicista e Outside-In
- Coroutines, Dispatchers e Structured Concurrency
- Kotlin Flow e coleta reativa de dados

> 📄 Arquivo: `anotacoes/Android TDD Masterclass - Coroutines, Jetpack.md`
